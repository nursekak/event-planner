# Event Planner - платформа для планирования мероприятий

Современная веб-платформа для создания, управления и координации мероприятий с интегрированной системой чатов.

## Описание проекта

Event Planner - это веб-приложение, разработанное для удобного планирования и управления мероприятиями. Система позволяет пользователям создавать мероприятия, приглашать участников и общаться с ними в режиме реального времени.

## Основные функции

- **Аутентификация пользователей**
  - Регистрация и авторизация
  - Личный кабинет с профилем пользователя
  - Настройки аккаунта

- **Управление мероприятиями**
  - Создание новых мероприятий
  - Редактирование деталей мероприятия
  - Удаление мероприятий

- **Система чатов**
  - Обмен сообщениями между пользователями
  - Отправка файлов
  - Поиск по сообщениям
  - Создание новых бесед
  - Удаление сообщений

- **Интерфейс**
  - Адаптивный дизайн
  - Поддержка светлой и тёмной темы
  - Интуитивно понятный пользовательский интерфейс

## Технологический стек

### Frontend
- React.js
- CSS3 (с использованием современных технологий)
- Адаптивный дизайн для всех устройств

### Backend
- Node.js + Express.js
- REST API
- База данных SQLite с Prisma ORM
- JWT для аутентификации

## Установка и запуск

### Требования
- Node.js (версия 14.x или выше)
- npm (версия 6.x или выше)

### Шаги установки

1. **Клонирование репозитория**
```bash
git clone https://github.com/Danteniu/FaB_semestrovoe_5.git
cd FaB_semestrovoe_5
```

2. **Установка зависимостей для бэкенда**
```bash
cd back
npm install
```

3. **Генерация Prisma клиента**
```bash
npx prisma generate
```

4. **Запуск бэкенда**
```bash
npm run dev
```

5. **Установка зависимостей для фронтенда (в отдельном терминале)**
```bash
cd ../front
npm install
```

6. **Запуск фронтенда**
```bash
npm run dev
```

7. **Доступ к приложению**
- Frontend: http://localhost:5173
- Backend API: http://localhost:3001

## Структура проекта
